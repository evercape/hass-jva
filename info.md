# JVA Electric Fence

Custom integration for a JVA PAE212 electric fence controller.

## Features

1. Set up from the Home Assistant UI with the controller's web username and password
2. Poll return voltage, alarm lamps, and arm or disarm Zone 1 and Zone 1a
3. Read firmware, MAC address, and network details without changing them
4. One logger name, `custom_components.jva_electric_fence`

## Installation

1. Click download.
2. Restart Home Assistant.
3. Add the **JVA Electric Fence** integration and follow the form.

See the [repository](https://github.com/evercape/hass-jva) for entity details, logging, and safety notes. Arm and disarm command the live energiser.
